📖 Project Introduction

บทนำโครงการ

ที่มาและความสำคัญ

โครงการ "Open Law Data Thailand" ริเริ่มขึ้นจากความตระหนักถึงปัญหาเชิงโครงสร้างในการเข้าถึงข้อมูลทางกฎหมายของภาคประชาชนและผู้ประกอบการ สืบเนื่องจากข้อมูลกฎหมายของภาครัฐในปัจจุบันยังมีความกระจัดกระจายและจัดเก็บในรูปแบบเอกสารที่ไม่เอื้อต่อการสืบค้นและการประมวลผล (Unstructured Data) ซึ่งถือเป็นอุปสรรคสำคัญต่อความโปร่งใสและการอำนวยความสะดวกในการดำเนินธุรกิจ

วัตถุประสงค์และภารกิจ

โครงการนี้มุ่งเน้นการปฏิรูประบบข้อมูลกฎหมายด้วยการเปลี่ยนผ่านจากรูปแบบเอกสารสู่ ข้อมูลดิจิทัลที่เครื่องอ่านประมวลผลได้ (Machine Readable) โดยดำเนินการ:

รวบรวมข้อมูลจากหน่วยงานภาครัฐต่าง ๆ มาไว้ ณ จุดเดียว (Centralized)
เชื่อมโยงระบบให้มีความเป็นปัจจุบัน (Real-time)
สร้างระบบนิเวศทางกฎหมายที่โปร่งใส ลดความซับซ้อน
ส่งเสริมให้เทคโนโลยีเข้ามามีบทบาทในการสร้างความเข้าใจด้านกฎหมายแก่สาธารณชน

กลไกความร่วมมือแบบบูรณาการ

ภาครัฐ (Data Owners)

ในฐานะผู้ถือครองข้อมูลต้นฉบับและเจ้าของกฎหมาย ที่พร้อมเปิดเผยข้อมูลสู่สาธารณะ

ภาคเอกชน (Innovators)

ผู้สนับสนุนนวัตกรรมและโครงสร้างพื้นฐานทางเทคโนโลยี

ภาคประชาสังคม

เครือข่ายนักพัฒนาและประชาชน ผู้ใช้งานจริงและผู้ตรวจสอบที่จะนำข้อมูลไปสร้างมูลค่าเพิ่มและประโยชน์ต่อสังคม

สถาปัตยกรรมระบบ

เราออกแบบระบบให้ทำงานอัตโนมัติ ยั่งยืน และไม่รบกวนเซิร์ฟเวอร์ต้นทาง

1. Data Aggregation

ระบบอัตโนมัติดึงข้อมูลจากแหล่งข้อมูลภาครัฐ บริหาร Traffic ไม่ให้รบกวนเซิร์ฟเวอร์ต้นทาง

2. Storage & OCR

แยกเก็บข้อมูลและประมวลผลภาพเป็นข้อความ (OCR) เพื่อให้ค้นหาได้ทุกตัวอักษร

3. Public Access

เปิดให้ดาวน์โหลดฟรีผ่าน Hugging Face เพื่อให้นักพัฒนานำไปสร้าง Legal Tech หรือ AI ได้ทันที

⚡ Powering the System

เทคโนโลยีเบื้องหลัง

ความสำเร็จในการพัฒนาระบบเกิดจากการสนับสนุนเทคโนโลยีชั้นนำจากพันธมิตรผู้เชี่ยวชาญ

"สนับสนุนเทคโนโลยีในการพัฒนาระบบ"

ช่วยให้การจัดการข้อมูลขนาดใหญ่เป็นไปอย่างรวดเร็วและมีประสิทธิภาพ เพิ่มข้อมูลเข้าสู่ระบบโดยอัตโนมัติ

"สนับสนุนเครื่องมือการทำ OCR"

เทคโนโลยีปัญญาประดิษฐ์สำหรับการแปลงภาพเอกสารเป็นข้อความที่มีความแม่นยำสูง

📊 Data Structure

โครงสร้างข้อมูล

เราจัดเก็บข้อมูลในรูปแบบมาตรฐาน JSON ที่นักพัฒนาคุ้นเคย พร้อมคำอธิบายฟิลด์ข้อมูลอย่างละเอียด เพื่อให้คุณนำไปใช้งานได้ทันที

example.json 
{
  "no": "92",
  "doctitle": "สารบัญ วันอาทิตย์ เดือนยี่...",
  "bookNo": "1",
  "section": "55",
  "category": "General",
  "publishDate": "1885-01-31",
  "pageNo": "479",
  "pdfFile": "1885-000092.pdf"
}
* ตัวอย่างข้อมูล Metadata (meta/) ดูข้อมูลทั้งหมด →

คำอธิบายชุดข้อมูล (Data Dictionary)

Field Type Description
no String รหัสอ้างอิงเอกสาร
doctitle String ชื่อเรื่องเอกสาร
publishDate Date วันที่ประกาศ (ISO 8601)
pdfFile String ชื่อไฟล์ต้นฉบับ (PDF)

Supported Formats

JSONL PDF Zip Archive
